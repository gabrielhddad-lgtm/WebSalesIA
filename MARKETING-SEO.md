## 📊 ANALYTICS & TRACKING

### Métricas de Aquisição

```
CAC (Customer Acquisition Cost)
= Total Spent / Customers Acquired
Target: < R$ 80 para PRO users

LTV (Lifetime Value)
= Average Revenue × Average Lifetime (meses)
= R$ 90 × 18 meses = R$ 1.620

LTV/CAC Ratio Target: > 20:1
(Significa que cada cliente vale 20x o custo)

Cost per Signup (Free)
= Spend / Signups
Target: < R$ 5

Conversion Rate (Free → Pro)
= PRO users / Total users
Target: 5-10%
```
